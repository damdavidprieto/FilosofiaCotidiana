📚 Sobre este proyecto

Filosofía Cotidiana acerca el pensamiento profundo a la vida real. Cada concepto incluye:

  • ✓ Una cita traducida de una obra concreta, o la idea resumida (marcada como tal)
  • ✓ El autor, su corriente y su época, con su red de maestros
  • ✓ Una aplicación práctica para tu vida hoy
  • ✓ Una pregunta para tu reflexión personal
  • ✓ Notas cuando la atribución popular no coincide con la histórica

Criterio de fuentes

Distinguimos entre «cita» e «idea resumida».
